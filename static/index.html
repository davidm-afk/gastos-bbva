Simulador de Notificaciones BBVA

Prueba cómo el sistema recibe, procesa y actualiza la pantalla al instante como si llegara la notificación a tu celular:

Vincular Samsung Galaxy A56 con MacroDroid

Tu Endpoint de Webhook:

  1. Descarga MacroDroid gratis desde Google Play Store en tu Samsung A56.
  2. En MacroDroid, toca «Añadir Macro»:
    • Disparador (Trigger): Notificaciones $\rightarrow$ Notificación recibida $\rightarrow$ Seleccionar Aplicación $\rightarrow$ Marca BBVA México (o SMS si recibes por SMS).
    • Acción: Conectividad $\rightarrow$ Solicitud HTTP (HTTP Request):
      • Método: POST
      • URL: [Pega la URL del túnel o IP local]
      • Content-Type: application/json
      • Contenido / Body: {"text": "[not_text]", "title": "[not_title]"}
  3. Guarda la Macro con el nombre «BBVA Débito Tracker» y ¡listo!
Acceso desde cualquier lugar (4G/5G): Usa el script start_tunnel.bat incluido en el proyecto. Te dará una URL pública HTTPS gratuita de Cloudflare (ejemplo: https://tu-token.trycloudflare.com/api/webhook/bbva).
